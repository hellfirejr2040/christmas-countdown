# Christmas Countdown Server

A beautiful, interactive Christmas countdown website built with Node.js and Express. Licensed and created by **Logan Ingle**.

## Features

- 🎄 Real-time countdown timer (days, hours, minutes, seconds)
- ✨ Beautiful festive animations and snowflake effects
- 🎅 Personalized greeting with your name
- 📅 Customizable year selection (2024-2050)
- 🎬 Movie suggestions
- 📰 Holiday news
- 💾 Remembers your name and year preference
- 📱 Fully responsive design

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the server:
```bash
npm start
```

3. Open your browser and visit:
```
http://localhost:3000
```

## Deployment

### Option 1: Deploy to Heroku
```bash
heroku create your-app-name
git push heroku main
```

### Option 2: Deploy to Replit
1. Create a new Replit project
2. Upload these files
3. Run the project

### Option 3: Deploy to Railway
1. Connect your GitHub repo
2. Deploy automatically

### Option 4: Deploy to Render
1. Create a new web service
2. Connect your repository
3. Set start command: `npm start`

## Environment Variables

Set the PORT variable if needed (default: 3000):
```bash
export PORT=8080
npm start
```
